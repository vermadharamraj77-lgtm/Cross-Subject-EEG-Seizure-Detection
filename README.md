# Cross-Subject EEG Seizure Detection

## Project Overview

This project aims to develop a deep-learning-based system for epileptic seizure detection using EEG signals.

The primary focus is **cross-subject seizure detection**, where the model is trained using EEG recordings from certain subjects and evaluated on previously unseen subjects.

## Objectives

- Analyze EEG signals
- Perform EEG preprocessing
- Segment EEG recordings
- Detect epileptic seizure segments
- Develop deep learning models
- Evaluate cross-subject generalization
- Compare model performance

## Dataset

CHB-MIT Scalp EEG Database.

Raw EEG data is not included in this repository.
